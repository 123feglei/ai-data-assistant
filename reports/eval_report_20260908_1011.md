### 34. [复杂组合] 取消率最高的前 5 个州是哪些？

- 结论：❌ 结果不一致(语义/聚合差异,需人工复核)（耗时 4.14s，LLM 调用 1 次）

**生成的 SQL：**

```sql
SELECT c.customer_state,
       COUNT(DISTINCT o.order_id) AS total_orders,
       SUM(CASE WHEN o.order_status = 'canceled' THEN 1 ELSE 0 END) AS canceled_orders,
       ROUND(SUM(CASE WHEN o.order_status = 'canceled' THEN 1 ELSE 0 END) * 100.0 / COUNT(DISTINCT o.order_id), 2) AS cancel_rate_pct
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id
GROUP BY c.customer_state
ORDER BY cancel_rate_pct DESC
LIMIT 5;
```

**金标准 SQL：**

```sql
SELECT c.customer_state,
       ROUND(SUM(CASE WHEN o.order_status = 'canceled' THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) AS cancel_rate
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id
GROUP BY c.customer_state
ORDER BY cancel_rate DESC
LIMIT 5;
```
